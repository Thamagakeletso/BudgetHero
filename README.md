A personal budget tracking Android app built with Jetpack Compose and RoomDB.

\## Features

\- 🔐 User login and registration with validation

\- 📁 Create and manage expense categories

\- 💸 Add expenses with date, time, description, category and optional photo

\- 🎯 Set minimum and maximum monthly spending goals

\- 📋 View expenses filtered by date range with photo access

\- 📊 View total spending per category for any selected period

\- 💾 All data stored locally using RoomDB (offline)



\## Tech Stack

\- \*\*Language:\*\* Kotlin

\- \*\*UI:\*\* Jetpack Compose (Material 3)

\- \*\*Database:\*\* Room DB

\- \*\*Navigation:\*\* Navigation Compose

\- \*\*Architecture:\*\* MVVM (ViewModel + StateFlow)

\- \*\*Images:\*\* Coil

\- \*\*CI/CD:\*\* GitHub Actions
